# Colossus Addon Mod - CAM Controller (Version 3.1.1)

Colossus Addon Mod is the popular SimCity 4 mod that involves substantial changes in the RCI (Residential - Commercial - Industrial) simulation as well as essential bugfixes. The mod was developed by the various members of the CAM Team who over time have brought modifications to improve this mod.

> **Warning:** from version 2.5 onward Colossus Addon Mod works only with the digital version (1.1.641) of SimCity 4 (Microsoft Windows and Linux only). On other systems the mod may malfunction and no support is provided.

Original readme: [`readme_Colossus_Addon_Mod.html`](readme_Colossus_Addon_Mod.html)

## Contents

The folder layout mirrors the original zip. Each `.dat` file is replaced by a folder of the same name containing its entries:

- [`CAM_Main_Controller.dat`](a_CAM/0%20CAM%20Controller/CAM_Main_Controller/INDEX.md) — 116 entries
- [`CAM_PlayStyle_Extended.dat`](a_CAM/0%20CAM%20Controller/CAM_PlayStyle_Extended/INDEX.md) — 13 entries

## Installation

The released package is a simple .zip file: extract the `a_CAM` folder to your `Documents\SimCity 4\Plugins` directory (or your custom Plugins folder). It is highly recommended to run the cleanitol and remove any previous versions from your plugins.

## Dependencies

- [SC4 System Integration Module (SIM)](https://community.simtropolis.com/files/file/36978-sc4-system-integration-module-sim/) — the essential dependency for CAM
- [Colossus Addon Mod - Ordinances](https://community.simtropolis.com/files/file/36878-colossus-addon-mod-ordinances/) — enhances and expands ordinances

DLL dependencies: none.
